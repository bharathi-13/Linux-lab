# Linux Troubleshooting Instructions
Consider your working in XYZ company. The Linux server in your organization have multiple problems, as a Linux administrator you need to troubleshoot all issue to make sure the server run properly again


### Root password breaking:

The company unfortunately forget the password of root account as an administrator reset the root password to gain the access again

### SSH:

The previous administrator already configure SSH the server, But the company can't able to take remote connection of the server, As a administrator make sure you can take SSH of the server again with key-base authentication

### Network:

The server was configure in DHCP connection. the company require you to configure the following IP in the server and make sure the server have internet connection.

-  IP address: 192.168.X.150

```
Note: Use the existing network for the following configuration 
```

### Package Management:

The company was unable to Install any packages in the server. Make sure the repositories are configured properly and able to install packages again.
